Humano SISU Bridge

Humano SISU remains the payroll system of record (Honduras statutory). This module receives employee cards and payroll journal entries as draft account.move. It does not install hr.payroll and does not post entries.

Assign group Humano SISU Bridge to a dedicated API user. Create an API key (max 90 days). SISU calls humano.sisu.bridge methods upsert_employee and import_payroll_move.
